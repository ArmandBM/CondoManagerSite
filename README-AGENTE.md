# Agente de débitos técnicos — CondoManagerSite

MVP genérico Python: o repositório não pôde ser consultado durante a preparação. Não assume Flask ou Django. Copie os arquivos para uma branch, revise e integre manualmente o workflow à branch padrão. Configure o secret OPENAI_API_KEY em Settings > Secrets and variables > Actions. Configure o comando real de instalação e testes em technical-debt-agent/test-command.txt antes de publicar. Em Settings > Actions > General permita criação de PRs por Actions. Proteja a branch padrão com revisão obrigatória, sem bypass para o agente. Execute em Actions > Technical Debt Agent > Run workflow. Comece com publish=false; baixe debt-proposals para revisar o diagnóstico. Depois execute publish=true para PRs draft independentes. Nenhum merge é executado pelo workflow. O token de publicação tem capacidade de escrita; a proteção de branch é indispensável. PRs criados pelo GITHUB_TOKEN podem não disparar outros workflows automaticamente. O limite de PRs é 1–5. A deduplicação por categoria/título é heurística. A validação não mede desempenho automaticamente; resultados dependem do comando real de testes. Revise/pine versões das Actions e Codex antes de uso em produção. Não use segredos de produção nos testes. O isolamento de código gerado neste MVP não é uma fronteira de segurança robusta; para produção use runner descartável isolado sem rede e sem credenciais, e valide artefatos independentemente antes da publicação. Vulnerabilidades sensíveis devem ser tratadas privadamente, não em PR público; revise o diagnóstico antes de habilitar publicação. O custo da API é separado do ChatGPT.
